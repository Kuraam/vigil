# Use of AI tools

**Code.** VIGIL's code was written with the assistance of Claude (Anthropic), an AI coding assistant, used through Claude Code. The team set the goals, the product decisions, the threshold values and their sources, the protocol content and the safety rules, and reviewed the results at each stage. Claude wrote the application code, the unit and browser tests, the scripts that make the screenshots and the deck PDF, and first drafts of the documentation, including this submission text, which the team reviewed.

**Content.** Thresholds, sources, hazard and risk wording, and protocol steps were supplied by the team from the cited NASA, CSA and clinical sources. The AI assistant was told not to add clinical facts, and protocols never name medications or doses. Rules the team defined itself are labelled as such in the app.

**Images.** No images were generated by AI. Every picture in the app, the README and the demo deck is a screenshot of VIGIL, taken by a script in the repository. The VIGIL mark and the Body Map figure are simple vector shapes written as SVG code with the coding assistant; no image-generation model was used.

**Data.** All crew members and readings are simulated by a seeded program. No real health data was used, and none was sent to an AI service.
